# Third-party components / 第三者コンポーネント

日本語: アプリ構造と最小libcは、GPL-2.0で公開されている
[`brain-hackers/exword-template`](https://github.com/brain-hackers/exword-template)
および[`brijohn/gnuboy-ex`](https://github.com/brijohn/gnuboy-ex)に由来します。
ビルドには`libdataplus`が必要ですが、このリポジトリには同梱していません。

English: The application structure and minimal libc derive from the GPL-2.0
[`brain-hackers/exword-template`](https://github.com/brain-hackers/exword-template)
and [`brijohn/gnuboy-ex`](https://github.com/brijohn/gnuboy-ex). Building also
requires libdataplus, which is not redistributed in this repository.
