# Stable app / 安定版

`XLLMI` is the normal EXLLM application. It loads `drv0:/MODELS/model.q12` and provides keyboard input, streaming output, optional Thinking mode, device information, and timestamped BMP screenshots.

`XLLMI`は通常利用向けのEXLLMです。`drv0:/MODELS/model.q12`を読み込み、キーボード入力、逐次表示、Thinking切替、端末情報、BMP画面保存を提供します。
